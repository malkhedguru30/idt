Smart Healthcare Monitoring System

Health Prime is a healthcare monitoring platform designed to track patient vitals in real time, detect abnormalities, and instantly notify doctors for faster medical response.

Project Overview View Demo

Project Overview

Problem Statement

Manual patient monitoring can delay emergency response and affect patient safety.

Solution

Automated patient monitoring with real-time data collection and alert generation.

Objective

Improve healthcare efficiency and provide faster doctor intervention.

Key Features

Real-Time Monitoring

Monitor BP, oxygen, heart rate, and glucose levels.

Alert System

Doctors receive notifications when readings are abnormal.

Secure Data

Patient records are stored securely in a centralized database.
